## Lo que hacemos

| | |
|---|---|
| **[NegocioContigo](https://negociocontigo.com)** | Página con catálogo, pedidos por WhatsApp, tienda en línea y caja (POS) que sigue vendiendo sin internet, con inventario y ganancia. En producción con negocios de Jamundí y Cali. |
| **ContrataSmart** | Gestión contractual para entidades públicas: contratos, cuotas, documentos y seguimiento en un solo lugar. |
| **Nexo Escolar** | Plataforma de gestión escolar para varias instituciones: admisiones, comunicados, calendario y pagos. |
| **Desarrollo a la medida** | Sistemas web para empresas y entidades: desde el diseño hasta el despliegue y el soporte. |
